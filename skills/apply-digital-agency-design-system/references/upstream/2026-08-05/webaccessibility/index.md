# ウェブアクセシビリティ （ 方針 ）

[2025年12月10日更新](changelog.md)

デジタル庁デザインシステムは、デジタル庁のミッションである「誰一人取り残されない、人に優しいデジタル化を。」の実現のために、また、ウェブというメディア特性を最大限に生かすために、アクセシビリティを最優先事項に位置付けて構築しているデザインシステムです。

デザインシステム本体である本ウェブサイトも、当然のこととして、日本産業規格JIS X 8341-3:2016「高齢者・障害者等配慮設計指針　情報通信における機器、ソフトウェア、及びサービス－第3部：ウェブコンテンツ」で定義された適合レベルAAには少なくとも準拠したうえで、よりアクセシビリティの向上に努めたかたちで情報提供をするものであります。

## 対象範囲

URLが https\://design.digital.go.jp/dads/ で始まる本ウェブサイト（デジタル庁デザインシステム専用サイト）全体。

ただし、コードスニペットのサンプル集（URLが https\://design.digital.go.jp/dads/html/ および https\://design.digital.go.jp/dads/react/ で始まるウェブページ群）は、Storybookで構築しているため、本ウェブサイトのアクセシビリティ方針の対象外とします。

※Storybookにはアクセシビリティに関する複数の問題があり、閲覧環境によってはコンテンツへ正しくアクセスできないことがあります。Storybookの表示が難しい場合は[GitHubリポジトリから直接ソースコードを取得してください](../resources/index.md#h2-%E3%82%B3%E3%83%BC%E3%83%89%E3%82%B9%E3%83%8B%E3%83%9A%E3%83%83%E3%83%88%EF%BC%88HTML%E7%89%88/React%E7%89%88%EF%BC%89)。

## 目標とする適合レベルと対応度

対象範囲に定義したすべてのウェブページについて、JIS X 8341-3:2016の適合レベルAAに準拠することを目標とします。\
加えて、WCAG 2.1、WCAG 2.2についても、AおよびAAの達成基準を順次追加していきます。

## 運用時におけるアクセシビリティ確保

本ウェブサイト公開後のコンテンツの追加・更新において、公開前にJIS X 8341-3:2016 に基づく試験を実施し、AAに準拠していることを確認して公開します。\
コンテンツ単位でのJIS試験通過をリリース判定の条件とし、AAに準拠できていない状態ではコンテンツを公開しません。

## 付記事項

### 対応度「準拠」の表記について

本方針及び検証結果における「準拠」という対応度の表記は、情報通信アクセス協議会ウェブアクセシビリティ基盤委員会「[ウェブコンテンツのJIS X 8341-3:2016 対応度表記ガイドライン – 2021年4月版](https://waic.jp/docs/jis2016/compliance-guidelines/202104/)」で定められた表記によるものです。

### Storybookのアクセシビリティに関する問題について

Storybookのシステム自体に起因し、修正が困難なアクセシビリティの問題は下記のとおりです。

#### 「達成基準 1.3.1 情報及び関係性 (レベル A)」において不適合

- 各ストーリーの個別ページにH1見出しが存在しない
- コンポーネントのサイズやタイプ、スペーシングなど設定を行うコントロールを含むテーブルについて、`th`でマークアップすべき箇所が`td`でマークアップされている
- コンポーネントのサイズやタイプ、スペーシングなど設定を行うコントロールについて、テキストフィールドやスピンボタンにラベルが設定されていない
- 「Show code」や「Copy」などのボタンについて、どのコードを表示したりコピーしたりするのかが不明確である

#### 「達成基準 2.1.1 キーボード操作可能 (レベル A)」において不適合

- ロゴ横の「Shortcuts」ボタン（歯車アイコン）を押して表示されるドロップダウンメニューに、キーボードでアクセスできない
