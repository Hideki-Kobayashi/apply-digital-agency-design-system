# デジタル庁デザインシステムβ版サイト（本ウェブサイト）ドキュメント（Markdown）

このzipアーカイブ（本アーカイブ）は、本ウェブサイトのコンテンツの一式を、主にAI参照用途としてMarkdown形式へ変換したものです。

人間が読むための一次情報としては、本ウェブサイトを参照してください。

* デジタル庁デザインシステムβ版
  https://design.digital.go.jp/dads/

## このアーカイブの目的

本アーカイブは、各AIツールから、DADSの各ページを参照しやすくすることを目的としています。

Markdown化にあたっては、各ページの見出し構造、本文、リスト、表、コードブロック、関連リンクなどを、AIが検索・引用・要約しやすい形で整理しています。

## 収録内容

本アーカイブには、本ウェブサイトのコンテンツ一式をMarkdown化したファイル群を収録しています。

各Markdownファイルには、原則として冒頭にYAML Front Matterを付与しています。

```yaml
---
title: 目次
category: components
slug: toc
document_type: reference
source_url: https://design.digital.go.jp/dads/components/toc/
language: ja
---
```

各項目の意味は次のとおりです。

* `title`: 本ウェブサイトでの（あるいはデジタル庁デザインシステムとしての）正式な日本語タイトル
* `category`: 本ウェブサイト上の大分類
* `slug`: URL、ファイル名、コード等で使われる識別子
* `document_type`: 文書種別
* `source_url`: 変換元の公式ページURL
* `language`: 本文の言語

収録ファイルの一覧は `MANIFEST.md` を参照してください。

## ファイル構成

ルートの `index.md` は、本ウェブサイトのトップページに相当するMarkdownファイルです。

各ディレクトリ配下の `index.md` は、そのディレクトリに対応する概要ページ（および使い方ページ・アクセシビリティページ等）、 `changelog.md` は更新履歴ページです。

## 利用上の注意

このアーカイブは、本ウェブサイトの内容を主にAI参照用途でMarkdownに変換・再構成したものです。そのため、本ウェブサイトそのものの完全体ではありません。完全な内容が必要な場合は、必ず各ファイルの `source_url` に記載された公式ページを確認してください。

## 出典

利用上の出典表記に関するルールは本ウェブサイト「利用上の注意事項」に従ってください。
https://design.digital.go.jp/dads/introduction/notices/

本アーカイブだけでなく、デザインシステム本体、デザインデータ、コードスニペット等の利用についても同様です。

## 本アーカイブに含まれる補助ファイル

本アーカイブには、本ウェブサイト由来の本文ファイルとは別に、AI参照用パッケージとしての補助ファイルを含みます。

* `README.md`: 本アーカイブの説明（このファイル）
* `MANIFEST.md`: 収録Markdownファイルの一覧

これらの補助ファイルは、本ウェブサイト由来の本文ではありません。
