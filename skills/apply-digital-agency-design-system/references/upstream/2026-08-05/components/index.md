# コンポーネント

コンポーネントは、ユーザーインタフェースを作成するためのデザイン構成要素です。

## コンポーネント一覧

- ### [アコーディオン](accordion/index.md)
  [アコーディオンは、同種のセクションが連続するとき、それらを折りたたんで一覧性を向上する目的で使用します。](accordion/index.md)
- ### [イメージスライダー](image-slider/index.md)
  [イメージスライダーは、ギャラリーコンテンツのように複数のイメージを切り替えて見ることができるコンポーネントです。](image-slider/index.md)
- ### [インプットテキスト](input-text/index.md)
  [インプットテキストコンポーネントは、名前や電話番号など、1行以内のテキストを入力する場合に使用します。](input-text/index.md)
- ### [引用ブロック](blockquote/index.md)
  [引用ブロックは段落単位での引用を表し、これ自体も段落となるコンポーネントです。](blockquote/index.md)
- ### [カード](card/index.md)
  [カードは、単一の主題に関するコンテンツをまとめて表示するコンテナとなるコンポーネントです。](card/index.md)
- ### [箇条書きリスト](list/index.md)
  [箇条書きリストは、1つ以上の項目を列挙するときに使用します。](list/index.md)
- ### [画像](image/index.md)
  [HTMLの\<img>に対応した、ページ中に画像を埋め込むためのコンポーネントです。画像キャプションと組み合わせて使うこともできます。](image/index.md)
- ### [カルーセル](carousel/index.md)
  [カルーセルは、複数のスライドを順番に見ることのできるコンポーネントです。ウェブサイトのアイキャッチとしても使われますが、使用に注意が必要なコンポーネントです。](carousel/index.md)
- ### [緊急時バナー](emergency-banner/index.md)
  [緊急時バナーは、当該ウェブサイトで本来成すべきコミュニケーションを中断してでもファーストビューを占有して注意を促すためのコンポーネントです。](emergency-banner/index.md)
- ### [検索ボックス](search-box/index.md)
  [サイト内検索等で使用するコンポーネントです。詳細検索パネルや固定のキーワードで検索できるショートカットパーツを備えています。](search-box/index.md)
- ### [コンボボックス](combobox/index.md)
  [コンボボックスは、標準のフォームコントロールだけでは実現困難な複合的な操作のできるコンポーネントです。HTMLの\<select>を拡張した選択支援タイプと\<input type="text">を拡張した入力支援タイプの2つがあります。](combobox/index.md)
- ### [スイッチ](switch/index.md)
  [スイッチは、切り替えたら即座に反映される設定項目のためのコントロールUIです。反映されたことがその場で目視により把握できる設定内容で使用できます。](switch/index.md)
- ### [水平メニュー](horizontal-menu/index.md)
  [水平メニューは、利用者を目的のページに誘導したり、コンテンツをわかりやすく表示するためのものです。](horizontal-menu/index.md)
- ### [スクロールトップボタン](scroll-top-button/index.md)
  [スクロールトップボタンは、ページの先頭へ迅速に移動するために使用されます。](scroll-top-button/index.md)
- ### [ステップナビゲーション](step-navigation/index.md)
  [一連の手続きを論理的なステップで提示して、完了までに必要な作業を俯瞰したり、進行状況を把握したりできるようにするコンポーネントです。ナビゲーションとして使用する場合もあります。](step-navigation/index.md)
- ### [説明リスト](description-list/index.md)
  [「説明したいこと」と「その説明文」のペアを1つの項目として数え、それが複数連なるようなコンテンツの時に使用します。](description-list/index.md)
- ### [セレクトボックス](select/index.md)
  [セレクトボックスは、複数の選択肢を提供するフォームコントロールです。](select/index.md)
- ### [タブ](tab/index.md)
  [クリアホルダーのインデックス用見出し（耳）をメタファーとしたタブラベルと、関連付けられたタブパネルの組み合わせのコンポーネントです。](tab/index.md)
- ### [チェックボックス](checkbox/index.md)
  [チェックボックスは、複数の項目の中から複数の選択肢を選ぶことを可能にします。](checkbox/index.md)
- ### [チップタグ](chip-tag/index.md)
  [アイテム化した任意の情報を、表示・削除しやすくするための要素です。属性やユーザー情報をアイテムにして並べたり削除したりするような場合に有効です。](chip-tag/index.md)
- ### [チップラベル](chip-label/index.md)
  [状態や状況を示すキーワードを表示して、情報の分類・整理の効率を向上させるグラフィック要素です。情報リストやテーブルの各行などのステータスを分かりやすく表示したい場合に有効です。](chip-label/index.md)
- ### [注釈ブロック](notice-block/index.md)
  [注釈ブロックは、強調された補足情報です。手続きフォームの入力内容に対するヘルプとして、具体的なサンプルのバリエーションや入力時に必要となる資料等の例示など、極めて有用な情報を補足する場合に使用すると効果的です。](notice-block/index.md)
- ### [ディスクロージャー](disclosure/index.md)
  [ディスクロージャーは、メイン情報に対する追加情報を折りたたんで提示するときに使用します。](disclosure/index.md)
- ### [ディバイダー](divider/index.md)
  [ディバイダーは、異なるセクション、コンポーネント、またはコンテンツのグループ間に設けられる視覚的な区切りです。](divider/index.md)
- ### [テーブルコントロール](table-control/index.md)
  [主にデータテーブルにおいて、表示する行や列を絞り込んだり、その他の制御操作を行ったりするための、コントロール群です。](table-control/index.md)
- ### [テーブル／データテーブル](table/index.md)
  [テーブルは、データや情報を行と列の組み合わせで構造化された表組です。](table/index.md)
- ### [テキストエリア](textarea/index.md)
  [テキストエリアコンポーネントは、自由記述テキストを入力する場合に使用します。](textarea/index.md)
- ### [ドロワー](drawer/index.md)
  [ブラウザ画面の四辺(上下左右端)から展開し、モバイルメニューなどのコンポーネントを格納可能なコンテナです。](drawer/index.md)
- ### [ノティフィケーションバナー](notification-banner/index.md)
  [ウェブサイト全体に関わる、またはページや要素単位における重要度の高い情報を、ユーザーの操作に関わらず、ウェブサイト側からユーザーへ提示する場合に用いる通知バナーです。](notification-banner/index.md)
- ### [パンくずリスト](breadcrumb/index.md)
  [パンくずリストは、ウェブサイトの階層内でユーザーの現在の位置を表示します。](breadcrumb/index.md)
- ### [ハンバーガーメニューボタン](hamburger-menu-button/index.md)

- ### [日付ピッカー／カレンダー](date-picker/index.md)
  [日付ピッカーは、日付を選択するためのフォームコントロールとして、入力フィールドおよびカレンダーによって構成されるコンポーネントです。](date-picker/index.md)
- ### [ファイルアップロード／ドロップエリア](file-upload/index.md)

- ### [プログレスインジケーター](progress-indicator/index.md)

## 達成基準の表記について

コンポーネントの各ページにおいて、JIS X 8341-3:2016およびWCAG 2.2の達成基準を掲載している箇所では、参照元のドキュメントを略称でバッジにしています。\
達成基準名はWAIC（ウェブアクセシビリティ基盤委員会）による日本語訳で表記しています。JIS X 8341-3:2016では異なる場合がありますので、達成基準番号をキーに照会してください。

- JIS2016

  このバッジが付与されている達成基準は、[JIS X 8341-3:2016](https://webdesk.jsa.or.jp/books/W11M0090/index/?bunsyo_id=JIS+X+8341-3%3A2016)に含まれています。なお、JIS X 8341-3:2016は[WCAG 2.0](https://waic.jp/translations/WCAG20/Overview.html)と同一内容の規格です。

- WCAG2.2

  このバッジが付与されている達成基準は、[WCAG 2.2](https://waic.jp/translations/WCAG22/)に含まれています。
