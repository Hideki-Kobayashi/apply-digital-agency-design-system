# ユーティリティリンク （ 概要 ）

[2025年1月9日更新](changelog.md)

![スクリーンショット：5つのユーティリティリンクが横並びになっている。](https://design.digital.go.jp/dads/images/components/utility-link/overview/utility_link_overview.png)

ユーティリティリンクはふつうの横並びリンクリストに近いが、それよりもコンパクトに作られています。

## 使い方

### 配置

ユーティリティリンクは通常、デスクトップビューでのヘッダーやフッターエリアなどが配置場所になります。

#### ヘッダーエリアでの配置例

![スクリーンショット：ヘッダーエリア内、ロゴの上部に右寄せでユーティリティリンクが配置されている図](https://design.digital.go.jp/dads/images/components/utility-link/overview/utility_link_layout_1.png)

#### フッターエリアでの配置例

![スクリーンショット：フッターエリア内、著作権表記の上部に中央寄せでユーティリティリンクが配置されている図](https://design.digital.go.jp/dads/images/components/utility-link/overview/utility_link_layout_2.png)

### 参考例

ユーティリティリンクに配置されるリンクはユーザーが頻繁にアクセスするリンク、例えば、「お問合わせ」、「よくあるご質問」、「ヘルプ」、「アクセス」など、また法的に必要性のある「プライバシーポリシー」などが含まれます。これらは、ユーザーが複数のページやメニューを経由せずに共通のタスクを実行したり、重要な情報にアクセスしたりするための便利なショートカットとして機能します。

#### ヘッダーエリアの参考例

![スクリーンショット：ユーティリティリンクの参考例。「お問合わせ」「よくあるご質問」「○○公式X（Twitter）」「アクセス」の4つのリンクが横並びになっている。](https://design.digital.go.jp/dads/images/components/utility-link/overview/utility_link_example_1.png)

#### フッターエリアの参考例

![スクリーンショット：ユーティリティリンクの参考例。「プライバシーポリシー」「リンク・著作権について」「免責事項」「アクセス」「アクセシビリティへの対応について」の5つのリンクが横並びになっている。](https://design.digital.go.jp/dads/images/components/utility-link/overview/utility_link_example_2.png)
